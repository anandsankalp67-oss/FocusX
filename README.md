# FocusX

A responsive productivity app built with HTML, CSS, and JavaScript to help students manage tasks and stay focused.

## Features
- Pomodoro focus and break timer
- Timer state saved after refresh
- Four customizable themes
- Task management and progress tracking
- Responsive design for mobile and desktop
- Local storage for saving data

## Tech Stack
- HTML
- CSS
- JavaScript
- Local Storage

## How to Run
1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Start managing tasks and focus sessions.
